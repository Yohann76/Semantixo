# 🚀 Scripts de test API Semantixo

Ce dossier contient des scripts pour tester les APIs de Semantixo en utilisant les variables d'environnement (.env).



### 1. Installer les dépendances
```bash
cd make-request
npm install
```

## 🚀 Utilisation

### Via npm scripts (recommandé)



```bash
# Recuperer un token via une connexion 
npm run get-token

# Copier le token dans make-request/config.js

# Tester une API spécifique
node test-analysis-text-seo.js
```
